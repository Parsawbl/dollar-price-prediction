# پیش‌بینی قیمت دلار در ایران (Dollar-Rial Price Prediction)

## درباره پروژه
این پروژه با استفاده از داده تاریخی نرخ دلار به ریال ایران، به تحلیل روند سری زمانی
(Time Series) قیمت پرداخته و یک مدل برای پیش‌بینی قیمت‌های آینده می‌سازد.

## داده
- منبع: [Kaggle - Dollar Rial Price Dataset](https://www.kaggle.com/datasets/mohammadtaghizadeh/dollar-rial-price-dataset)
- بازه زمانی: ۲۰۱۱ تا ۲۰۲۳ (تقریباً هر روز)
- تعداد رکورد: ۳,۳۱۰
- ستون‌ها: Date، Persian_Date، Open، Low، High، Close

## ساختار پروژه
```
data/raw/           داده خام اصلی
data/processed/     داده پاک‌سازی‌شده
notebooks/          تحلیل و مدل‌سازی
src/                کدهای قابل استفاده مجدد
```
